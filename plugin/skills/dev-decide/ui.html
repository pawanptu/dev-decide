How it works

The fastest answer it can trust.

Every question walks down the tiers and stops at the first one that has earned trust for it. Most stop in the first three, on your own machine, for free.

01

Rules

Exact facts: a live API key, a migration file, docs-only changes.

~3 msfree
02

Learned model

Your trained model, used only above the confidence it proved on held-out data.

<1 msfree
03

Memory

Your own corrections, and inputs like ones already answered.

~1 msfree
04

Claude

One lean call for whatever is still open, with the local findings as evidence.

2–4 s~$0.001
05

Stronger model

Unsure answers to the decisions that matter, capped per day.

+5 s~$0.02

It gets faster and cheaper the more you use it.

Each answer Claude gives becomes a label. The local model trains on it, and it only replaces the current one after proving it is better on your own decisions. It can always roll back.

80% of questions answered locally in steady use (README simulation).

One call, a whole judgment.

Bundles ask several typed questions at once and apply a pass, review or block gate. Pick one to try it with an example.

route :: <task>

incident :: <log>

Install

Two commands in Claude Code.

It runs on your machine and asks Claude with your own sign-in or your own ANTHROPIC_API_KEY. Nothing is shared.

Starter models, a documented settings file and the routing hint are included.

/plugin marketplace add pawanptu/dev-decide
/plugin install dev-decide@dev-decide
/dev-decide pr :: DIFF

For the HTTP API on your computer, or to choose whether to add the routing hook.

git clone https://github.com/pawanptu/dev-decide
python3 dev-decide/dev-decide-v5/install.py --router-hook

See which agent or skill was suggested for which task, what Claude really used, and how long each step took.

/plugin install dev-decide-graph@dev-decide
/dev-decide-graph
Or open http://127.0.0.1:47321/graph while Claude Code runs.

Private by design

  • Decides locally first; only unsure questions reach Claude.
  • Logs predictions only, never your input text.
  • Learned data stays in your repo's git-ignored .claude/dev-decide/.
  • Switches models only after a challenger proves better on your own decisions, and can roll back.
  • Standard-library Python. No pip installs.
